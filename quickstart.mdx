This guide walks you through everything you need to go from a blank ScriptHub account to a hosted Lua script running live inside Roblox. By the time you finish, you'll have a script in the cloud, a `loadstring` URL to call it, and proof it executes — all in under 5 minutes.

## Prerequisites

Before you begin, make sure you have the following:

- A free **ScriptHub account** — sign up at [scripthub.io](https://scripthub.io) if you don't have one yet.
- **Roblox Studio** installed on your machine.
- **HttpService enabled** in your Roblox game (Game Settings → Security → Allow HTTP Requests).

## Steps

<Steps>
  <Step title="Sign Up">
    Go to [scripthub.io](https://scripthub.io) and click **Sign Up**. Fill in your email and password, then verify your email address. Once confirmed, you'll land on the ScriptHub dashboard.
  </Step>
  <Step title="Create Your First Script">
    From the dashboard, click **New Script**. Give your script a name — for example, `HelloWorld` — then paste the following Lua code into the editor:

    ```lua
    -- HelloWorld.lua
    print("Hello from ScriptHub!")
    print("Script loaded at: " .. os.time())
    ```

    Click **Save**. ScriptHub stores your script and makes it available at a hosted URL immediately.
  </Step>
  <Step title="Copy Your loadstring URL">
    After saving, open the script's detail page. You'll see a **Script URL** field containing a link in this format:

    ```text
    https://scripthub.io/s/{scriptId}
    ```

    Click **Copy URL** to copy it to your clipboard. This URL always serves the latest saved version of your script.
  </Step>
  <Step title="Execute in Roblox">
    Open Roblox Studio and create a new `LocalScript` (or `Script`) inside **StarterPlayerScripts** (or **ServerScriptService**). Delete any placeholder code, then paste the following — replacing the URL with your own:

    ```lua
    loadstring(game:HttpGet("https://scripthub.io/s/YOUR_SCRIPT_ID"))()
    ```

    Your file should look something like this when complete:

    ```lua
    -- LocalScript in StarterPlayerScripts
    loadstring(game:HttpGet("https://scripthub.io/s/abc123"))()
    ```
  </Step>
  <Step title="Verify">
    Press **Play** in Roblox Studio to run the game. Open the **Output** panel (View → Output). You should see:

    ```text
    Hello from ScriptHub!
    Script loaded at: 1718000000
    ```

    If those lines appear, your script is running successfully from ScriptHub. Any future changes you save to the dashboard will be reflected the next time the game executes the `loadstring` call — no Studio republish needed.
  </Step>
</Steps>

<Tip>
  Enable HttpService in Game Settings → Security before executing remote scripts. Without it, `game:HttpGet()` will throw an error and your script will not load.
</Tip>
